# 画像保存ツール

ログインが必要なサイトの画像一覧をブラウザで操作し、画像クリック後に取得できる高解像度画像を保存する Windows 向けツールです。

## 目的

ブラウザ上では直接保存できない画像について、ユーザーがログインした状態を利用して、画像一覧から高解像度画像を順番に保存します。

## 想定する利用方法

1. ユーザーがリモートデバッグ対応の Chrome を起動する
2. ユーザーがブラウザ上で手動ログインする
3. ユーザーが対象の画像一覧画面まで開く
4. ツールがそのブラウザの画像通信を監視する
5. 一覧をスクロールし、Network に発生する画像レスポンスを自動保存する

パスワードはツールに保存しません。

## 初期要件

| 分類 | 要件 |
| --- | --- |
| 認証 | 初回のみユーザーが手動ログインする |
| セッション | ログイン状態を保存し、次回以降に再利用する |
| 対象 | ユーザーが指定した画像一覧ページ |
| 一覧 | 無限スクロールに対応する |
| 画像 | クリック後の高解像度画像を保存する |
| 保存先 | ユーザーが指定したフォルダ |
| 制御 | 最大保存件数、スクロール間隔、停止操作を指定できる |
| 重複 | 同じ画像を重複保存しない |
| エラー | 失敗した画像を記録し、可能な限り処理を継続する |
| 配布 | 最終的に Windows の `.exe` として実行できる |

## 技術方針

初期実装では **Python + Playwright** を使い、Chrome DevTools Protocol (CDP) でユーザーが開いたブラウザへ接続します。ユーザーのログイン操作や対象画面への移動は自動化しません。

画像 URL をコピーして別タブで開き、右クリック保存する代わりに、ブラウザが受信した画像レスポンスの本体をそのまま保存します。これにより、ログイン Cookie、Referer、User-Agent、一時 URL などを含む現在のブラウザセッションを利用できます。URL の重複を除き、同じ画像の二重保存を避けます。

## 段階的な開発計画

### Phase 1: 取得方式の検証

- 手動でブラウザを起動する
- 手動でログインし、対象画面まで開く
- Network に発生する画像レスポンスを監視する
- 画像レスポンスを一枚ずつ保存する

### Phase 2: 一覧処理

- 表示中の画像を検出する
- 未処理画像をクリックする
- 一覧を一定量スクロールする
- 新しく表示された画像を検出する
- URL やサイト上の識別子で重複を除く
- 最大件数と停止操作に対応する

### Phase 3: GUI

- 対象ページ URL の入力
- 保存先フォルダの選択
- 最大保存件数の指定
- スクロール間隔の指定
- 開始・停止ボタン
- 成功件数、失敗件数、処理状況の表示

### Phase 4: 配布

- Windows `.exe` 化
- 初回ログイン手順の整備
- エラーログと設定の保存

## 先に確認する事項

対象サイトごとに、以下を検証してから本実装を進めます。

- Network の画像リクエストの Content-Type が `image/*` になっているか
- 画像 URL のパスに拡張子や一意な ID が含まれているか
- 高解像度画像のレスポンス本体を保存できるか
- 一覧画面を開いた時点で取得される画像と、スクロール後に取得される画像を区別できるか
- スクロールによる追加読み込みの完了を判定できるか
- Chrome のログインセッションで画像レスポンスを保存できるか

対象サイトの利用規約、著作権、アクセス制限を守って利用します。大量アクセスを避けるため、取得間隔と処理件数を制御できるようにします。

## Phase 1 の実行

Python 3.11 以上を用意し、プロジェクトのルートで以下を実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
playwright install chromium
```

通常の Chrome をすべて終了した状態で、専用のユーザーデータフォルダを指定して起動します。既存の Chrome を閉じたくない場合は、別の `--user-data-dir` を使用してください。

```powershell
& "$env:ProgramFiles\Google\Chrome\Application\chrome.exe" `
	--remote-debugging-port=9222 `
	--user-data-dir="$PWD\.data\chrome-profile"
```

開いた Chrome で手動ログインし、対象の画像一覧画面まで移動します。別の PowerShell で次の監視を開始します。

```powershell
python -m app.phase1 `
	--cdp-url "http://127.0.0.1:9222" `
	--output-dir output
```

監視開始後に画像一覧を開く、または過去の画像を表示するためにスクロールします。Network に発生した `image/*` レスポンスが `output` に保存されます。対象外の画像通信がある場合は、`--url-contains` に画像 URL に共通する文字列を指定します。終了は `Ctrl+C` です。
